Plans for this project:

This is susposed to be a website that you download on your proxmox host per git clone, and then start per one command. It is susposed to be simple, but very detailed. Every single info is susposed to be shown about the hardware and the software. 

The Website is susposed to be available with no log in or whatever. 

The main view has to have the status of each ct and vm: 
running or not running?
ram reserved, and how much ram is being used. 
ram swap reserved, and how much ram swap is being used.
Cpu reserved and how much cpus are being used (info per each core/thread)
how much storage the ct/vm has reserved and how much being used.


By pressing on a Ct/Vm you get a new window, where you see more detailed infos about it, what files are inside this ct/vm and a console where you can write and get responses just like on a normal proxmos server. The file showcase should be as simple as a windows explorer with the ability to drag and drop, and also do drag files out of it to be dropt on the users computer/device. by installing extraction tools like for example zip, the explorer shows a "extract" or "zip" or whatever fits better to files (like explorer in windwos)
